# УБ Байр — статик хувилбар

Улаанбаатарт байр худалдаж авах, түрээслэхэд эрсдэлийг нь шалгадаг сайт. Зөвхөн **HTML, CSS, JavaScript** дээр ажилладаг тул сервер, database шаардлагагүй, **GitHub Pages дээр үнэгүй** байрлана. Утас болон компьютерт тохирсон.

## GitHub Pages дээр байрлуулах

1. GitHub дээр шинэ repo үүсгэнэ (жишээ нь `ubbair-static`, **Public**).
2. Энэ хавтасны **доторх бүх файлыг** repo-ийн үндсэн хавтсанд оруулна. `index.html` нь repo-ийн хамгийн дээд түвшинд байх ёстой.
   - Терминалаар:
     ```bash
     cd ubbair-static
     git init
     git add -A
     git commit -m "УБ Байр статик сайт"
     git branch -M main
     git remote add origin https://github.com/ТАНЫ_НЭР/ubbair-static.git
     git push -u origin main
     ```
   - Эсвэл GitHub вэб дээр **Add file → Upload files** хэсэгт файлуудаа чирж оруулаад **Commit changes** дарна.
3. Repo-ийн **Settings → Pages** хэсэгт **Source: Deploy from a branch**, **Branch: main**, хавтас **/(root)** сонгоод **Save** дарна.
4. 1–2 минутын дараа сайт `https://ТАНЫ_НЭР.github.io/ubbair-static/` хаягаар нээгдэнэ.

Компьютер дээрээ туршихдаа `index.html` файлыг шууд давхар товшиж нээхэд болно.

## Анхаарах зүйлс

- **Өгөгдөл browser-т хадгалагдана.** Бүртгэл, зар, гэрээ, дневник тухайн хүний browser-т (localStorage) хадгалагддаг. Өөр төхөөрөмж дээр харагдахгүй. **Тохиргоо → Нөөц татах/сэргээх**-ээр шилжүүлж болно.
- **Демо админ:** `admin@ubbair.mn` / `admin1234`. Админаар нэвтэрч зар зөвшөөрөх үйл явцыг туршина.
- **AI зөвлөх** түлхүүргүйгээр сайтын мэдлэгийн сан, өгөгдлөөс хариулна. **Тохиргоо** хэсэгт Groq түлхүүр оруулбал Llama загвараар ярилцана. Түлхүүр зөвхөн тухайн browser-т хадгалагдана.
- **Газрын зураг** анхдагчаар Esri-ийн суурь зургийг ашиглана. Газрын зургийн баруун дээд талын давхаргын товчоор OpenStreetMap эсвэл хиймэл дагуулын зураг руу шилжиж болно.
- **Эрсдэлийн оноо** нь нээлттэй өгөгдөл дээр автоматаар тооцоолсон зөвлөмж бөгөөд хуулийн баталгаа биш.
